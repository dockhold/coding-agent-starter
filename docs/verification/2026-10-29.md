means a real app on Dockhold, deployed from this repository.

## Local checks

* `node --test tests/unit.test.mjs tests/loop.test.mjs`: 42 tests, all pass.
  They include an end-to-end run of the loop against a fake GitHub API and
  a fake agent that misbehaves.
* `tests/smoke.sh`: 28 cases, all pass. The header of that file says how it
  runs the image the way Dockhold runs apps, and the two ways it goes
  further (no outbound network and a read-only root for the start-up
  checks).
* The agent never sees the GitHub token, through its environment or through
  another process's `/proc` files. Proved by an adversarial test with a
  paired control: the same read works on a process that is meant to be
  readable.
* A repository's own `.claude/` hooks and `.mcp.json` never load. Proved
  with the real Claude Code binary and a control.
* Only issues opened by people with write access to the repository run.
* A task that keeps getting cut short stops after 3 tries and says so on
  the issue.
